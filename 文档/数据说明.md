# 数据说明（存档 / 配置表 / 可调参数）

改存档或配置前先关服务端，改完再启动。改前备份。

## 1. 玩家存档：`hakimi.db`（SQLite）

位置由启动参数 `--data` 决定（仓库脚本为 `06_构建\hakimi.db`，不带参数为 `server\data\hakimi.db`）。可用 DB Browser for SQLite 打开。

| 表 | 内容 |
|---|---|
| `accounts` | 每个账号一行：`account` 账号、`player_id` 角色 ID、`hero_id` 主角卡 ID、`role_name` 角色名、`starter_hero` 初始英雄、`created_ms/updated_ms` 时间、`state_json` **全部进度** |
| `metadata` | 仅 `schema_version`，勿改 |

### `state_json` 常用字段

| 字段 | 含义 |
|---|---|
| `player` | `{level, exp}` 玩家等级、经验 |
| `wallet` | 货币：`copper` 元宝（游戏内主货币）、`gold` 仙玉（充值）、`gift` 仙玉（赠送）、`inter` 仙玉、`friendship` 友情点数、`fragment` 万能碎片、`coupon` 背包扩充券、`exploit` 精魂、`purple` 紫晶币、`orange` 橙晶币、`stone`、`totalCharge` 累计充值 |
| `action_points` | 体力类：`"0"` 体力（关卡消耗），其余为其他玩法点数 |
| `cards` | 拥有的卡：`{id 唯一编号, base_id 卡种(=BaseHero.id), level, exp, locked, power_skill, skill_exp}` |
| `groups` | 阵容（`embattles` 为 3×2 格子，存卡 `id`；`leaderId` 队长） |
| `items` | 背包：`{id, base_id(=ItemConfig.id), type, amount}` |
| `equips` / `talismans` | 装备 / 法宝（`hero` 为穿戴它的卡 id，0 表示未穿戴） |
| `battles` / `campaigns` | 已通关的关卡 / 章节（BattleInfoConfig.id / CampaignConfig.id） |
| `elite`、`elite_campaigns` | 精英关进度 |
| `daily_counts` | 今日关卡次数 |
| `mails` | 邮件 |
| `social` | 好友（机器人 id ≥ 90000000） |
| `menpai`、`arena`、`demog`、`explore`、`vip` 等 | 对应玩法进度 |
| `next_uid` | 下一个唯一编号；手动加卡/物品时用比它大的数，并同步调大它 |

手动加卡示例（加到 `cards` 数组）：`{"id": 99001, "base_id": 11, "level": 1, "exp": 0, "locked": false, "power_skill": 0, "skill_exp": 0}`

## 2. 游戏配置表：`05_改造\data\config_dump.json`

从原版 `db.dat` 导出，服务端所有规则从这里读。**改这里只影响服务端结算，客户端界面显示的数值来自 APK 内 db.dat，不会变。**

| 表 | 内容 |
|---|---|
| `BaseHero` | 所有卡片：`name`、`star` 星级、`race` 种族、`initValues` 初始属性、`initGrows` 成长、`powerSkill` 技能、升级/进阶消耗 |
| `HeroLevelConfig` | 卡片升级经验 |
| `LevelConfig` | 玩家每级：`exp` 升级经验、`packSize` 背包、`leadership` 统御、`friends` 好友上限 |
| `ItemConfig` | 物品：名称、品质、售价、叠加上限 |
| `BaseEquip` | 装备及属性 `alters` |
| `BattleInfoConfig` | 关卡：`level`、`cost` 体力、`enemies` 波数、`itemDrop` 掉落 |
| `CampaignConfig` | 章节 |
| `RewardConfig` | 奖励包 |
| `ShopItemSetting` | 商店商品 |
| `ChargeGoods` | 充值档位 |
| `TaskSetting` | 任务 |
| `ComposeConfig` | 合成 |
| `RandName` | 随机名（机器人名字） |
| `_key_8f7cc034` | 原服参数 ConfigValue（初始账号、体力恢复、价格等 580 项） |
| `_key_0411dd75` / `_key_963314ef` | 每日签到 / 首次签到 |

## 3. 可调参数：`server\config\server_settings.json`

原服缺失、由我们推测的数值都在这里，改完重启服务端生效：

| 分组 | 内容 |
|---|---|
| `battle` | 敌人强度、每波敌人数、元宝/经验公式（经验 = 体力 ×（`exp_per_cost` + 关卡等级 × `exp_per_cost_level`））、掉率、首战赠卡 |
| `elite` / `rebirth` | 精英关 / 转生奖励 |
| `lottery` | 卡池内容、价格、概率 |
| `shops` | 各刷新商店的商品来源 |
| `demog` / `hunt` / `menpai` / `mail` / `activities` | 魔神、寻宝、门派、邮件、活动 |

## 4. 美术资源：`01_解包\assets\`

图片、音效、界面、文字（`ini\strres.ini`）。已打包在 APK 里，改这里需重新构建 APK 才生效。
