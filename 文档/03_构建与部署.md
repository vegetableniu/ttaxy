## 构建 APK

在项目根目录执行：

```powershell
$env:OFFLINE_DEBUG = "1"
$env:OFFLINE_STANDALONE = "1"
Remove-Item Env:OFFLINE_DUMP_CODES -ErrorAction SilentlyContinue
python 09_脚本\17_gen_localserver.py
python 09_脚本\18_build_offline.py
```

产物为 `06_构建\hakimi_offline.apk` 和 `06_构建\script_offline.dat`。当前 Lua 编译基线是 14/14。

## 启动服务端

```powershell
Set-Location server
python -m hakimi_server.server --host 127.0.0.1 --port 19019 --data ..\06_构建\hakimi.db
```

另一个终端建立调试转发：

```powershell
$adb = "D:\leidian\LDPlayer14\adb.exe"
& $adb -s emulator-5554 reverse tcp:9001 tcp:19019
```

客户端每次登录前都会设置 `127.0.0.1:9001`，干净安装不依赖旧偏好文件。

## 快速替换 Lua

调试包的 `files/assets/script.dat` 会覆盖 APK 内脚本并跨覆盖安装保留。只改 Lua 时同步新脚本并重启应用：

```powershell
$adb = "D:\leidian\LDPlayer14\adb.exe"
& $adb -s emulator-5554 push 06_构建\script_offline.dat /data/local/tmp/hakimi_script.dat
& $adb -s emulator-5554 shell run-as com.eyugame.ahxy.mi cp /data/local/tmp/hakimi_script.dat files/assets/script.dat
& $adb -s emulator-5554 shell am force-stop com.eyugame.ahxy.mi
& $adb -s emulator-5554 shell am start -n com.eyugame.ahxy.mi/com.eyugame.game.ActivityMain
```
