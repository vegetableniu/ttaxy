# 哈基米西游本地服务器版：项目文档入口

本项目的目标是保留《哈基米西游 1.0.8.0》客户端的画面、规则、数值、引导、活动和操作流程，只把已经停止或不可访问的远程服务端替换为本机服务端。

原版 APK 是唯一行为基线：`C:\Users\nkq\Desktop\game\哈基米西游_1.0.8.0.apk`。工作样本 `00_原始样本/game.apk` 与它的 SHA-256 一致。

## 阅读顺序

1. `01_目标与边界.md`：什么必须保持一致，哪些改动允许存在。
2. `02_项目结构.md`：目录、生成物和脚本职责。
3. `03_构建与部署.md`：从原版样本构建、安装、保留存档迭代。
4. `04_测试矩阵.md`：每个功能的验证状态和证据要求。
5. `05_过程记录.md`：已确认的根因、修复和未完成事项。
6. `06_协议与服务端覆盖.md`：客户端协议、本地处理器和缺口。
7. `协议覆盖自动生成.md`：由 schema 和当前 handler 自动生成的逐命令清单。

## 当前判断

现有 `LocalServer.lua` 是嵌入客户端进程的伪服务端，适合逆向协议和快速验证，但它不是最终目标要求的独立本地服务器。现阶段保留它作为协议参考和测试夹具；最终方案应让客户端仍按原通信路径连接 `127.0.0.1` 上的本地服务。

任何“默认返回 0/空表即可不报错”的命令都不算实现。只有与原客户端期望的数据结构、状态变化、错误码和持久化行为一致，并完成实机路径验证，才能在测试矩阵中标为通过。
